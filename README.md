# 💰 Khata - Personal Finance Manager

A full-stack web application for tracking income, expenses, and visualizing your financial data.

## 🚀 Live Demo

**Try it here:** [https://khata-iota.vercel.app](https://khata-iota.vercel.app/)

> Note: First load may take 30-50 seconds (free tier backend wakes from sleep)

---

## ✨ Features

- 🔐 **Secure Authentication** - JWT-based login/register with encrypted passwords
- 💸 **Transaction Management** - Add, edit, delete income and expenses
- 📊 **Visual Analytics** - Pie charts and bar graphs for spending insights
- 📱 **Responsive Design** - Works seamlessly on mobile and desktop
- 🎯 **Category-based Tracking** - Organize transactions by categories
- 💰 **Real-time Summary** - Instant overview of income, expenses, and balance

---

## 🛠️ Built With

**Frontend:** React, Tailwind CSS, Recharts  
**Backend:** Node.js, Express, MongoDB  
**Auth:** JWT, bcrypt  
**Deployed on:** Vercel (Frontend) + Render (Backend)
